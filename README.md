# Lachgas Amsterdam

Onafhankelijk, niet-commercieel informatieplatform over lachgas in Amsterdam (Nederlands en Engels).

```bash
npm install
npm run dev            # http://localhost:3000
npm run check          # typecheck + lint + content-audit
npm run build && npm start
```

Zet vóór livegang `NEXT_PUBLIC_SITE_URL` op het productiedomein.
